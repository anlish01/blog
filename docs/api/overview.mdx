## 基础信息

| 项目 | 值 |
|------|-----|
| 基础路径 | `/api/` |
| 数据格式 | JSON |
| 认证方式 | `Authorization: Bearer <token>` |

## 端点列表

### 文章

| 方法 | 路径 | 认证 | 说明 |
|------|------|------|------|
| `GET` | `/api/posts` | ❌ | 文章列表 |
| `GET` | `/api/posts/:id` | ❌ | 单篇文章 |
| `POST` | `/api/posts` | ✅ | 创建文章 |
| `PUT` | `/api/posts/:id` | ✅ | 更新文章 |
| `DELETE` | `/api/posts/:id` | ✅ | 删除文章 |

### 评论

| 方法 | 路径 | 认证 | 说明 |
|------|------|------|------|
| `GET` | `/api/posts/:id/comments` | ❌ | 文章评论 |
| `POST` | `/api/posts/:id/comments` | ❌ | 发表评论 |
| `GET` | `/api/comments` | ✅ | 全局评论（管理） |
| `PUT` | `/api/comments/:id` | ✅ | 更新评论状态 |
| `DELETE` | `/api/comments/:id` | ✅ | 删除评论 |

### 统计 / 管理 / 媒体 / 设置

详见各 API 页面。

## CORS 策略

- 配置了 `SITE_URL`：仅允许本站来源
- 未配置：回退为回显请求源

所有响应包含 `Vary: Origin` 头。

## 错误响应

```json
{
  "ok": false,
  "error": "错误描述"
}
```

| 状态码 | 说明 |
|--------|------|
| `400` | 参数错误 |
| `401` | 未认证 |
| `403` | 无权限 |
| `404` | 不存在 |
| `429` | 频率限制 |
| `500` | 服务器错误 |
