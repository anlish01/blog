## 完整配置示例

```javascript
window.BLOG_CONFIG = {
  mode: 'auto',
  apiBase: '',
  siteUrl: '',
  writeToken: '',
  pageSize: 5,
  adminPwd: '',

  footer: {
    text: '',
    icp: '',
    contact: [],
    links: [],
    decl: '',
    email: '',
    startYear: 2019,
    copyrightName: "Qingyu'Blog"
  },

  ads: {
    enabled: false,
    belowSearch: '',
    between: '',
    betweenEvery: 3,
    content: ''
  }
};
```

## 基础配置

### mode

| 值 | 说明 |
|----|------|
| `'auto'` | **（推荐）** 自动检测：请求 `/api/posts` 成功 → 云端；失败 → 静态 |
| `'static'` | 强制静态模式，只用 `posts.js` |
| `'api'` | 强制云端模式，需要后端 API |

### apiBase

后端 API 基础地址。

- **留空**（默认）：同源请求
- **填写 URL**：如 `https://xxx.workers.dev`（跨域时后端需已配 CORS）

### siteUrl

站点对外地址，用于生成 RSS/Sitemap 链接。如 `https://blog.example.com`。

### pageSize

首页每页显示文章数。设为 `0` 不分页。

### adminPwd

| 模式 | 行为 |
|------|------|
| 云端模式 | **请留空**。密码在 D1 后端，前端拿不到 |
| 静态模式 | 可填固定密码，或留空让浏览器本地设置 |

## 页脚配置 (footer)

| 字段 | 类型 | 说明 |
|------|------|------|
| `text` | `string` | 页脚自定义文字 |
| `icp` | `string` | 备案号 |
| `contact` | `Array` | 联系方式列表 `{text, url}` |
| `links` | `Array` | 友情链接列表 `{text, url}` |
| `decl` | `string` | 站点声明 |
| `email` | `string` | 联系邮箱 |
| `startYear` | `number` | 版权起始年 |
| `copyrightName` | `string` | 版权署名 |

## 广告配置 (ads)

| 字段 | 类型 | 说明 |
|------|------|------|
| `enabled` | `boolean` | 总开关 |
| `belowSearch` | `string` | 首页列表上方 HTML |
| `between` | `string` | 列表间隔插入 HTML |
| `betweenEvery` | `number` | 每 N 篇插入（默认 3） |
| `content` | `string` | 文章详情底部 HTML |

## 路由

所有路由为真实路径，无 hash：

| 路径 | 页面 |
|------|------|
| `/` | 首页 |
| `/archive` | 归档 |
| `/about` | 关于 |
| `/tags` | 标签云 |
| `/posts/<别名>/` | 文章详情 |
| `/admin` | 管理后台 |
| `/write` | 写作台 |
