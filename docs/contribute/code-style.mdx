## 核心原则

| 原则 | 说明 |
|------|------|
| **零依赖** | 不引入第三方库 |
| **零构建** | 不用 Webpack/Vite |
| **零框架** | 纯原生 JavaScript |
| **可读性** | 代码即文档 |

## JavaScript 规范

### 文件头

```javascript
/* ============================================================
 * 轻语博客 · 功能名称
 * ------------------------------------------------------------
 * 简要说明此文件的职责。
 * ============================================================ */
```

### 命名

| 类型 | 风格 | 示例 |
|------|------|------|
| 变量 | camelCase | `postData`, `isAdmin` |
| 函数 | camelCase | `handlePosts()`, `dbAll()` |
| 常量 | UPPER_SNAKE | `READ_CACHE`, `LIKE_CAP` |
| 文件 | kebab-case | `api-core.js` |

### 缩进

2 空格。

## SQL 规范

- 使用 `CREATE TABLE IF NOT EXISTS`
- 索引 `CREATE INDEX IF NOT EXISTS`
- 查询使用参数化

## CSS 规范

- CSS 变量定义主题色
- 响应式断点统一

## Git 规范

分支命名：`feature/`、`fix/`、`docs/`、`refactor/`

Commit 格式：[Conventional Commits](https://www.conventionalcommits.org/)

```
feat(comments): add nested reply support

Implement parent_id field for comment threading.

Closes #42
```
