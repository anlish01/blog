## v1.0

### ✨ 核心功能

- 零框架、零构建、零依赖的博客系统
- 双通道架构：静态模式 + 云端模式
- Cloudflare Workers + D1 部署
- Markdown 编辑器
- 文章加密（PBKDF2 + AES-GCM）
- 评论系统（嵌套回复 + 审核）
- 阅读/点赞统计
- 站内搜索 + TOC
- RSS / Sitemap 自动生成
- 精选文章推荐

### 🎨 界面

- 深色/浅色主题切换
- 响应式设计（手机/平板/桌面）
- 四级衬线字体栈

### 🌐 国际化

- 内置 5 种语言
- 自动识别 + 手动切换

### 🔒 安全

- PBKDF2-SHA256 密码哈希
- 会话 Token 鉴权
- 登录限流
- CORS / XSS / SQL 注入防护
